# 1. Hello World 출력하기

**난이도:** ★

## 문제

화면에 `Hello World` 를 출력하는 프로그램을 작성하시오.

**출력 예시**
```
Hello World
```

## 내 코드

```c
#include <stdio.h>

int main(void) {
    printf("Hello World\n");
    return 0;
}
```

## 모범 답안

```c
#include <stdio.h>

int main(void) {
    printf("Hello World\n");
    return 0;
}
```
