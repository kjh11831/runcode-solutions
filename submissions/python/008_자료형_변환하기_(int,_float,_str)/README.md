# 8. 자료형 변환하기 (int, float, str)

**난이도:** ★

## 문제

숫자로만 된 문자열 두 개를 입력받아, 문자열 그대로 이어 붙인 결과, 정수로 바꿔 더한 결과, 실수로 바꿔 나눈 결과(소수점 둘째 자리까지)를 출력하세요.

[입력] 첫째 줄: 숫자 문자열 x / 둘째 줄: 숫자 문자열 y
[출력]
문자열로 더하면: (x와 y를 이어 붙인 것)
정수로 더하면: (x + y)
실수로 나누면: (x ÷ y, 소수 2자리)

## 내 코드

```c
x = input()
y = input()
print(f"문자열로 더하면: {x + y}")
print(f"정수로 더하면: {int(x) + int(y)}")
print(f"실수로 나누면: {float(x) / float(y):.2f}")
```

## 모범 답안

```python

y = input()
print(f"문자열로 더하면: {x + y}")
```
