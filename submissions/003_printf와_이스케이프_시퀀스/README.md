# 3. printf와 이스케이프 시퀀스

**난이도:** ★

## 문제

이스케이프 시퀀스를 사용해 아래 두 줄을 정확히 출력하세요. 둘째 줄은 탭 문자로 시작하며, 큰따옴표를 포함합니다.

[입력] 없음
[출력]
그가 큰 소리로 말했다.
	"여러분! 침착하세요."

## 내 코드

```c
#include <stdio.h>

int main(void) {
    printf("그가 큰 소리로 말했다.\n\t\"여러분! 침착하세요.\"");
    return 0;
}
```

## 모범 답안

```c
#include <stdio.h>
int main(void)
{
    printf("그가 큰 소리로 말했다.\n");
    printf("\t\"여러분! 침착하세요.\"\n");
    return 0;
}
```
